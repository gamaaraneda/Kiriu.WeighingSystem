Demostración del Sistema de Mensajes

Estos mensajes simulan las notificaciones automáticas del sistema de pesaje.

Los toasts son notificaciones que aparecen en la esquina superior derecha.

🎯 Características del Servicio de Mensajes

  • Mensajes Automáticos: Para entradas y salidas del sistema de pesaje
  • Mensajes Personalizados: Con título, mensaje y duración configurables
  • Múltiples Tipos: Éxito, Error, Advertencia, Información
  • Toasts: Notificaciones emergentes en diferentes posiciones
  • Duración Configurable: Desde 1 segundo hasta 10 segundos
  • Responsive: Adaptable a diferentes tamaños de pantalla

🚀 Cómo Usar en tu Aplicación

1. Importar el servicio:

import { MessageService } from './shared/services/message.service';

2. Inyectar en el constructor:

constructor(private messageService: MessageService) {}

3. Usar en tu componente:

// Mensaje de éxito para entrada
this.messageService.showEntrySuccess('ABC-123');

// Mensaje de error personalizado
this.messageService.showError({
  title: 'Error de Validación',
  message: 'Por favor complete todos los campos.',
  duration: 3000
});

📱 Componente de Visualización

El componente app-message-display debe estar incluido en tu aplicación principal (por ejemplo, en app.component.html) para que los mensajes se muestren correctamente. 

<app-message-display></app-message-display>
