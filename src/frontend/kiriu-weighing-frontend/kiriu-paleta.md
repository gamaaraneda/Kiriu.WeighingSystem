# Paleta de Colores Kiriu

## 1. Introducción

**Objetivo:** Especificar la paleta de colores que se utilizará en el
diseño de la interfaz de software desarrollado para Kiriu Mexicana S.A.
de C.V. ya sean desarrollos internos o externos.

**Alcance:** Este documento detalla los colores base, sus usos
previstos, variantes (tonos), y recomendaciones de contraste.

------------------------------------------------------------------------

## 2. Resumen de la Paleta Principal

  -------------------------------------------------------------------------------
  Color        Código HEX             RGB             Uso principal
  ------------ ---------------------- --------------- ---------------------------
  🔵 Azul      #398DF1                rgb(57, 141,    Botones principales,
                                      241)            títulos, inputs, combo box,
                                                      encabezado de tablas y
                                                      calendario.

  ⚪ Blanco    #FFFFFF                rgb(255, 255,   Fondo principal, texto de
                                      255)            letras dentro de inputs y
                                                      combo box, iconos.

  ⚫ Negro     #000000                rgb(0, 0, 0)    Texto de etiquetas

  🟡 Naranja   #FF914D                rgb(255, 145,   Botón edición, mensajes de
                                      77)             advertencia, inputs con
                                                      cambios.

  🔴 Rojo      #F70000                rgb(247, 0, 0)  Mensajes de error, botón
                                                      cancelar, inputs de error.

                                      51)             aceptar y reporte excel,
